\# Interactive Leaks Battery Calibration Data



This directory contains version-controlled seed calibration data for the PhoneFuturist Interactive Leaks battery simulation system.



The purpose of this dataset is not to create a leaderboard of phone battery life.



Its purpose is to preserve real-world measurements that can be used to develop, calibrate, and validate Battery Experience models.



For the full calibration philosophy and evidence rules, see:



`docs/INTERACTIVE\_LEAKS\_CALIBRATION.md`



For the overall product specification, see:



`docs/INTERACTIVE\_LEAKS\_SPEC.md`



\---



\# 1. Core Rule



Store observations, not conclusions.



A calibration record should describe what was actually measured.

Device: Galaxy S25 Ultra

Protocol: Notebookcheck Wi-Fi Web
