## Reproduced from implementation

- BOM MSRP is calculated from total × multiplier while profit/margin use retail; those can disagree.
- CommunityPeople fetch has no deadline, retry button or explicit loading/error state model.
- Studio renders both workflow state and Published for a published row.
- Simple panel is outside the workspace grid; Advanced form is inside it.
- Canvas chart uses a fixed bitmap/layout, with an unconstrained threshold annotation and no ResizeObserver.
- Image-less story cards omit the media block entirely; no fallback or broken-image handling.
- Global styles repeatedly override colors, shadows/radii, typography and outer main containers.

## Allowed additions only

Confidence tags and optional Studio field; responsive result summaries; long-form sections/current-value summaries; input suffixes; specified loading/retry/empty feedback; Suggest a lab; functional motion/toasts. No image asset, crop/filter treatment, existing route/copy or simulation/calibration changes.

## Evidence and verification

Run node scripts/audit-ui-preservation.mjs after edits to compare native control identities and route presence against the baseline. The final report will separately distinguish source preservation, automated interaction tests and checks that cannot be exercised with available sessions/tooling. A source match is not proof that every production control works.

## Deliberate exceptions and release boundary

1. Native accordion height changes are not animated: the brief also requires animation of transform/opacity only. Chevron rotation and a short content fade provide feedback without animating layout height.
2. Hardware material colors, artwork and image treatment remain outside interface palette normalization. Imagery was not recolored, replaced or recropped. The requested hero containment is the only image sizing correction.
3. The new migration 20261103135403_article_confidence_label.sql validates the optional JSON field and exposes it through the existing public projection. It was exercised in local PostgreSQL/WASM tests; it was **not applied to Supabase**. Your earlier requirement for explicit database approval still applies. Category-derived tags need no database migration, but per-article overrides require this migration before release.
4. No production deployment was requested for this refinement. No deployment, remote database change or merge to main was performed.
5. No new placeholder/editorial marketing content was shipped. Additional text is restricted to the requested status, error, confidence, input-unit and suggestion affordances.
